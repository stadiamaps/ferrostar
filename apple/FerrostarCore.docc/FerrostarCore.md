# FerrostarCore

Ferrostar is a modern, open-source navigation SDK built from the ground up for customizability.

## Overview

The `FerrostarCore` framework provides the fundamental architectural building blocks for turn-by-turn navigation on Apple platforms, managing everything from route parsing to state transitions and location updates.
